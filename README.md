# 方寸 Diorama

[English README](README.en.md)

> 不用搬，就能换个摆法；不用买，就能先摆上看看。
> Rearrange your room without lifting a finger. Try it before you buy it.

上传一张房间照片，在 3D 里重新摆家具：照片变成可以转动的 3D 房间，原来的家具可以擦掉、换成新模型，家具库里的真实商品能直接摆进去，桌上的台灯、托盘、杯子都能叠着放。识别、抠图和背景修复都在这台 Mac 上完成，只有生成 3D 时才会用到服务商积分。

页面有中文和英文两版，顶栏品牌名右边的“ZH | EN”开关可以点，也可以左右拖动；选择会记在这台电脑的浏览器里。

## 启动

双击 **启动方寸.command**，或在项目目录执行：

```bash
npm start
```

需要 Node.js 22.13 或更高版本。启动时会检查本地模型、更新数据库，然后在 <http://localhost:5173> 提供服务、准备好演示卧室，并用 Chrome 打开页面。不想自动打开浏览器时，用 `NO_OPEN=1 npm start`。

## 黑客松演示流程

演示用的照片在 `resources/demo/`：`bedroom.jpg`（有床、书桌、衣柜的卧室）、`bed.png`（白底床照片）和 `pendant.png`（吊灯商品图）。

1. 打开首页，可以先切换中英文、拖一拖右边的木作模型、点“白天 / 黄昏”。
2. 点“上传照片”，选 `resources/demo/bedroom.jpg`。工作台认出这张照片（文件内容或照片指纹），新建空间“卧室”，直接打开它的 **Marble 1.1** 房间：地面已对齐，空房间底图已就位，不调用 World Labs，0 积分。
3. 打开顶部工具栏的“挪动原家具”，在 3D 房间里点床，选“是，上传照片”。（不打开这个开关时，点房间不会弹出提示。）床的类别、尺寸和擦除框已经填好；上传 `resources/demo/bed.png`，页面提示“之前已经生成过 3D 模型，直接复用”。点“擦除原家具并放回模型”，原来的床消失，生成好的床模型立刻出现在原位，可以拖动、旋转，0 积分。
4. 在家具栏点“添加家具”，选 `resources/demo/pendant.png`：名称、类别（吊灯）和尺寸自动填好，提示不消耗积分，点“放进家具栏”立刻出现。点它，再点天花板（或它下方的地面），吊灯挂到天花板上，拖动时沿天花板移动。
5. 打开家具库，挑台灯、托盘、杯子放到书桌或床上；用“帮我找”问“50 美元以内的灯”或 “a lamp under $50”；看价格和官网链接，最后保存。
6. 演示结束后，可以在首页“全部空间”里删除这个演示空间；演示卧室的文件放在 `presets/` 下，床和吊灯模型在 `public/demo/`，都不属于任何空间，删除空间不会影响下一次演示。

其他照片照常走流程：上传后第一步就是“直接生成 3D 房间（草稿 · 约 230 积分）”，生成前会再确认一次。页面同时提示：草稿版偏糊，想要更清晰的房间，可以去 Marble 官网用 Marble 1.1 生成同一张照片，再粘贴链接导入（不消耗本工作台积分）。草稿房间打开后，3D 视图上方也会给出这条提示。“先处理家具（可选）”里仍然可以识别、移除或单独生成家具；可用内存不足 3 GB 时，自动识别会跳过并说明原因。

换一台电脑时先运行 `npm ci`。第一次启动会下载背景修复模型 LaMa（约 208 MB），之后识别和修复都不再需要联网。

## 浏览器

推荐 **Chrome 或 Edge**，Safari 也能用。macOS 上的 Safari 17 以前打开 3D 房间会崩溃：Spark 的两个 WebAssembly 线程同时开始解码房间文件时，Safari 的 JavaScript 引擎会出错。现在房间文件按顺序加载，并关掉了用不到的细节层级线程，在这台 Mac（Safari 17.5）上连续打开 3 次都正常（见 `docs/VALIDATION.md`）。

直接打开某个空间：`http://localhost:5173/?space=<空间 id>`，彩排或录屏时可以用。

## 在线演示版（Vercel）

不用安装，打开网址就能体验示例卧室。在线版是同一套页面的静态构建，没有服务器：页面的接口在浏览器里运行（`lib/demo-backend.ts`），空间和照片存在访问者自己浏览器的 IndexedDB 里，房间文件直接从 World Labs 的 CDN 读取。不调用任何付费接口，也不需要密钥。

- **能做**：打开示例卧室（Marble 1.1 房间）；打开“挪动原家具”点床，擦掉原来的床、放回床模型；添加示例吊灯并挂到天花板；家具库全部商品、叠放、“帮我找”、价格和官网链接；保存、改名、删除空间；中英文切换。首页的“看示例卧室”，以及编辑面板和添加家具里的“用示例……照片”按钮，直接用 `public/demo/samples/` 里的照片，不用自己找文件。
- **不能做**：用其他照片生成房间或家具、导入 Marble 链接、本机识别和背景修复。页面会提示“在线演示版只能体验示例卧室”，完整功能请在本地运行。

部署（`vercel.json` 已写好构建命令和输出目录，Framework Preset 选 **Other**，不用改任何设置）：

- 在 Vercel 网站 **Add New → Project** 导入这个 GitHub 仓库；或者
- 在项目目录执行 `npx vercel`（登录由你自己完成），确认无误后 `npx vercel --prod`。`.vercelignore` 保证 `.dev.vars`、`.wrangler/` 等本机文件不会被上传。

本地预览在线版：

```bash
npm run build:demo
npm run demo:preview
```

然后打开 <http://localhost:5191>。构建产物在 `dist-demo/`（约 16 MB，含家具库模型、示例床和吊灯）。

注意：在线版是公开网页，家具库的产品图和吊灯示例照片来自品牌官网（见 `docs/SOURCES.md`），公开前请确认使用范围。

## 主要功能

- **我的空间**：首页列出所有空间，可以继续上次的、打开、重命名或删除。删除时，别的空间还在用的房间文件会保留。
- **照片 → 3D 房间**：
  - 上传房间照片后，本机的 DETR + SlimSAM 自动框出家具，LaMa 补全被挡住的墙面和地板。
  - 3D 房间可以通过 World Labs 生成，也可以导入在 Marble 官网生成好的房间：粘贴嵌入代码或链接即可，免费下载。
  - 地面会自动校准，房间按真实尺寸（米）显示。
- **同一张照片不重复生成**：
  - 房间：照片指纹相同（重新保存、压缩过的也算），直接复用已有的 3D 房间，不再花积分。
  - 家具：同一个文件之前用 Tripo 高精度生成过模型，直接复用那个模型，不建新任务。以前用标准设置生成的不复用，会按高精度重新生成。
- **把房间里的家具变成可编辑的**：
  1. 打开工具栏的“挪动原家具”，点 3D 房间里的家具。蓝色方框会按房间扫描自动贴合这件家具，并填好尺寸和类别（`lib/fit-box.ts`）；可以再微调，或点“自动贴合方框”重新贴合。
  2. 上传一张这件家具的照片。方框里的原家具从房间里擦掉，同时由 Tripo 生成新模型，放回原来的位置。
  3. 可以导入一个“空房间”作为底图，擦掉的地方会用空房间的墙面和地板补齐。
- **摆放**：
  - 家具会落在指针对准的表面上：地面、桌面、床面、窗台，包括 3D 扫描里原有的书桌。
  - 指着家具侧面时，会放到它的顶上；指着墙或衣柜门时不放下，家具留在原处。
  - 移动、旋转桌子时，桌上的东西一起走；收回桌子时，上面的东西落到下面的表面上。
  - 壁挂家具用“离地”调整高度挂到墙上，用“落下”放回下面的台面。
  - 吊灯吊在天花板上：类别选“吊灯”或名字里有“吊灯 / pendant”的家具，摆放时自动挂到指针所指位置的天花板下，拖动时沿天花板移动（天花板高度从房间扫描里估计，窗边的吊顶梁也认得出）。其他家具也可以在面板里打开“吊在天花板”。
  - 照片比例和填写尺寸差别很大时（例如只填了灯罩的高度，模型还带着吊杆），模型按照片比例等比缩放，不再被压扁，面板会标注“按照片比例”。
- **家具库**：
  - 20 件真实商品，带 3D 模型、尺寸、美元参考价、官网链接和库存说明。
  - 可以直接拖进房间，家具栏会显示房间里家具库商品的参考合计。
  - “帮我找”能理解“不超过 1 米的书桌”“50 美元以内的灯”“500 元以内的小东西”这类说法。
- **添加家具**：上传照片里没有的家具照片，用 Tripo 高精度生成模型（H3.1，精细几何，8K PBR 贴图）后按真实尺寸摆放。房间里显示的是 4K 副本（最多 20 万–40 万个三角面），8K 原件保留，可以在家具面板里下载。以前生成的家具可以在家具栏或面板里“高精度重新生成”，新模型好了之前旧模型照常显示。

## 3D 生成与花费

图片处理（识别、抠图、修复）免费。只有下面两项会用到服务商积分：

| 服务 | 用途 | 每次预计 |
|---|---|---|
| World Labs（Marble 草稿模型） | 由照片生成 3D 房间 | 230 积分 |
| Tripo H3.1 高精度（精细几何 + 8K PBR 贴图） | 生成一件家具的 3D 模型 | 70 积分 |

需要生成时，把 `.env.example` 复制为 `.dev.vars`，用文本编辑器填好 `WORLDLABS_API_KEY` 和 `TRIPO_API_KEY`，再重启工作台。不要把密钥写进其他文件。

付费保护：
- 每次提交前都要确认预计积分。
- 本地有预算上限（`.dev.vars` 里的 `WORLDLABS_CREDIT_LIMIT` 和 `TRIPO_CREDIT_LIMIT`），失败的任务会释放预留的积分。
- 无法确认是否已经提交的任务会标为“待核对”，不会自动重新提交。
- 等待超时只会继续查询原任务，不会重新生成。

## 本机数据

| 位置 | 内容 |
|---|---|
| `.wrangler/state/` | 空间数据库、照片、房间和家具文件。**不要删除**，删了就会丢失所有空间。 |
| `.local/models/` | LaMa 背景修复模型（启动时自动下载并校验）。 |
| `public/vision/models/` | 随项目提供的识别模型（DETR、SlimSAM）。 |
| `public/catalog/` | 家具库的产品图和压缩后的 3D 模型。 |
| `public/demo/` | 演示用的床模型（1.3 MB）、吊灯模型（2.5 MB）和缩略图。 |
| `resources/demo/` | 演示用的卧室照片、床照片和吊灯商品图。 |
| `.dev.vars` | API 密钥，不会提交到 git。 |

## 开发与测试

```bash
npm run typecheck
npm test
npm run scan
npm run lint
```

- `npm test`：所有离线测试，网络全部模拟，不会产生任何付费调用。包括 provider、家具、空间（含演示卧室、模型复用和重新生成）、家具库搜索（中英文）、摆放、自动贴合（擦除框、天花板、模型缩放）、在线演示版接口和双语检查八组。
- `npm run scan`：提交前检查，确认 `.dev.vars` 里的密钥没有出现在任何要提交的文件里。
- `node tests/local-workflow.mjs`：需要工作台已在运行、可用内存约 3 GB，会真实运行识别和修复模型，并新建一个测试空间，测完可以在首页删除。
- `node tests/recognition-smoke.mjs`：不需要服务，直接用随项目提供的模型识别两张参考图。
- `npm run catalog`：维护家具库（`scripts/build-catalog.mjs`）。用 `--images <文件夹>` 从官网产品图重新生成卡片图片。

## 主要文件

- `components/editor/Workbench.tsx`：页面和全部流程；`Landing.tsx` 是首页，`Maquette.tsx` 是首页的木作模型，`LangToggle.tsx` 是语言开关。
- `lib/i18n.ts`：中英文切换，界面文字都写成 `t("中文", "English")`。
- `lib/demo-room.ts`、`lib/server/demo.ts`：演示卧室（照片、Marble 1.1 房间、底图、床模型）和模型复用。
- `components/editor/Scene.tsx`：3D 视图（three.js + Spark）。
- `lib/placement.ts`：摆放规则，即家具落在哪里、谁叠在谁上面；也从扫描里估计天花板和墙的朝向（新放下的家具与墙对齐）。
- `lib/fit-box.ts`：从房间扫描里找出被点中的家具，给出贴合它的擦除框。`lib/fit-model.ts`：生成的模型按填写尺寸缩放的规则。
- `lib/credits.ts`：每次生成预计花费的积分。
- `app/api/workbench/route.ts`：本地服务端接口（空间、上传、生成任务、家具库）。
- `demo/`、`vite.demo.config.ts`、`lib/demo-backend.ts`、`vercel.json`：在线演示版（静态页面、浏览器里的接口、Vercel 设置）。`lib/asset-url.ts` 决定文件从哪里读取（本地服务或在线版的 CDN / 浏览器）。
- `lib/server/`：任务、预算、服务商调用、存储。
- `build/local-*-plugin.mjs`：只允许本机访问的辅助服务（本地模型、模型压缩、代理转发）。
- `lib/catalog.json`：家具库数据，价格与链接来源见 `docs/SOURCES.md`。

更多说明见 `docs/ARCHITECTURE.md`（结构）、`docs/SOURCES.md`（来源与许可证）和 `docs/VALIDATION.md`（实测记录）。
