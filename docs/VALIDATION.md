### 报错 “send was called before connect”

- **原因**：
  - 开发服务器是从 Claude Code 后台启动的，Vite 8 检测到“代理环境”，默认打开了 `server.forwardConsole`，把浏览器的 warn/error 和未处理异常转发到服务器。
  - 页面里的 Grammarly 水合警告和 three.js 的 `PCFSoftShadowMap` 废弃警告都会被转发。
  - HMR 连接断开后（例如电脑休眠），转发本身抛出这个错误，这个错误又被转发，于是反复弹出。
- **修复**：
  - `vite.config.ts` 固定 `forwardConsole: false`；
  - `<html>`、`<body>` 加 `suppressHydrationWarning`；
  - 阴影改用 `PCFShadowMap`。
- **验证**：重启后 `/@vite/client` 里 `forwardConsole` 为 `{"enabled":false,…}`；首页和房间页控制台没有这两条警告。
