# 线下演示清单

上台前照着做一遍。演示用本机版（`npm start`），不依赖线上站；评委扫码用线上站 <https://diorama.3dspace.workers.dev>。

## 前一天

- 电脑充满电，带电源线和 USB-C 转 HDMI 转接头。
- 关掉系统自动更新，不在演示前升级任何软件。
- 准备好备用视频：`demo-video/Diorama-demo-v2.mp4`（2 分 11 秒），拷一份到桌面。
- 打印或导出展板和二维码：`visual-assets/boards/`、`visual-assets/qr/`。
- 在 `.dev.vars` 里填好 `DEEPSEEK_API_KEY`（帮我布置用；没有也能演示，会按规则挑选）。
- 断网彩排一次：关掉 Wi-Fi，从下面“开场前”第 2 步开始走完整个流程。

## 开场前 30 分钟

1. 接上电源，打开勿扰模式，关掉不用的应用（3D 房间和本机识别都要内存）。
2. 双击 **启动方寸.command**（或在项目目录运行 `npm start`），等终端出现“演示卧室已就绪”。
3. 防休眠：另开一个终端窗口运行 `caffeinate -d`，演示结束后按 Ctrl+C。
4. 用 **Chrome** 打开 <http://localhost:5173>，缩放 100%，按 ⌃⌘F 全屏。接上投影后看一眼：1920×1080 和 1280×720 都检查过。
5. 首页 → “全部空间”，删掉上一次演示留下的“卧室”空间（演示卧室的文件在 `presets/`，删空间不会影响它）。不要删「我的空间」。
6. 在访达里打开 `resources/demo/`，里面有 `bedroom.jpg`、`bed.png`、`pendant.png`，上传时直接选。
7. 语言：评委看中文就切 ZH，看英文就切 EN（顶栏品牌旁的开关）。

## 演示流程（约 3 分钟）

| 步骤 | 操作 | 说什么 |
|---|---|---|
| 1. 首页（15 秒） | 拖一拖右边的木作模型，点“黄昏” | “方寸之间，摆出心里的家。” |
| 2. 一张照片变 3D（30 秒） | 点“上传房间照片”，选 `bedroom.jpg`；房间打开后拖动转一圈，点左侧“原图”对照 | “这是我租的房间，只拍了一张照片。World Labs Marble 把它变成能走进去的 3D 空间，地面和比例自动对齐。” |
| 3. 挪动原有的家具（40 秒） | 点左侧手形按钮“挪动原家具”→ 点床 →“是，上传照片”→ 选 `bed.png` →“擦除原家具并放回模型”；然后拖动、旋转这张床 | “照片里的床本来是死的。点一下，它就被擦掉，Tripo 用床的照片生成 3D 模型放回原处，现在可以挪了。” |
| 4. 高潮：一句话布置（40 秒） | 点左侧工具栏下面的深色 ✦ 按钮，点“温馨一点的卧室，预算 600 美元”（或者自己说一句）；等家具一件件落下 | “空落落的出租屋，一句话：AI 从真实商品库里挑家具，摆到合适的位置，告诉我为什么这样搭，总共多少钱。” |
| 5. 前后对比（15 秒） | 点“撤销这次布置”，再点 ✦ 重新布置；或者用左下角的撤销 / 重做来回切 | “这是之前，这是之后。” |
| 6. 买得到（20 秒） | 点顶栏的购物袋：商品、价格、官网链接、合计；点一个“去官网” | “每一件都是真实商品，尺寸是真的，价格和链接来自品牌官网。” |
| 7. 收尾（10 秒） | 投出二维码 | “扫码就能在手机上试，示例卧室和家具库都能用。” |

时间紧时跳过第 3 步，直接从第 2 步到第 4 步。

## 出问题时

- **帮我布置很慢或断网**：DeepSeek 9 秒内没回答，或者没网，就自动按规则布置，卡片右下角会写“按规则挑选”。照常讲下去。
- **3D 房间加载慢**：先讲首页和照片；还不行就播备用视频的对应片段。
- **线上站打不开**（中国大陆网络访问 `workers.dev` 不稳定）：说明线上站部署在 Cloudflare，现场网络访问不了；用投屏继续演示，会后把视频和截图发给评委。
- **页面出错**：刷新一下（布置都已保存在本机）；还不行，在终端按 Ctrl+C，再双击 **启动方寸.command**。
- **不要用 Safari 演示**，用 Chrome。

## 演示结束后

- 首页 → 全部空间，删掉这次演示的“卧室”空间。
- 停掉 `caffeinate`，关掉终端窗口。
